## Leads API

Now you can use our CRM API to get the leads generated by your ads in Encuentra24

This is the endpoint URL:

https://www.encuentra24.com/api.php/v1/crm/index

### API key

In your requests, you have to add your API key in a header named x-api-key. **Your API key is:**

**66745cd97e505**

### Company slug parameter

You have to add a GET parameter with the name of your company. The name of the parameter is slug and the value, for your company, is tu-auto-ideal.

### Extra parameters

Without any extra parameters, this API method will return the **last 50 leads** generated in Encuentra24 for all your ads.

Optionally, you can pass an ad ID (as a GET parameter) in order to get **all the leads** generated for that specific ad. There are two ways you can pass it, choose one of them:

- adid This is the Encuentra24 ad identifier. You can find it in the list of your ads in your Encuentra24 account section.
- sourceid In case you are publishing your ads in Encuentra24 using the XML/XLS feed, this is the identifier of the ad **on your system**.
- agent This is the email of the agent
- fromdate This will filter leads where dates are greater or equal than the record date. When use this filter response will use **pagination format.**
- todateThis will filter leads where dates are less or equal than the record date. When use this filter response will use **pagination format.**
- limit This will allow to define how many records can be returned, between a range from 1 to 1000 records. When use this filter response will use **pagination format.**
- fromid This is the lead ID where the records will be start to filter, **it is necessary for pagination.**

### Examples of requests

- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal will return the leads in the last hour.
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&adid=123456 will return all leads for your ad with Encuentra24 ID 123456
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&sourceid=7890 will return all leads for your ad with ID 7890 on your company's system
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&agent=john.doe@company.com will return the leads in the last hour for the agent email
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&fromdate=2024-08-15 will return the maximum (1000) leads from 2024-08-15 and the response will use the paginated format described below.
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&todate=2024-08-15 will return the maximum (1000) leads until 2024-08-15 and the response will use the paginated format described below.
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&fromdate=2024-08-15&todate=2024-08-16 will return the maximum (1000) leads between 2024-08-15 and 2024-08-16 and the response will use the paginated format described below.
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&fromdate=2024-08-15&limit=50 will return the maximum 50 leads from 2024-08-15 and the response will use the paginated format described below.
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&fromdate=2024-08-15&limit=50&fromid=123456 will return the maximum 50 leads from 2024-08-15 starting from the lead with ID 123456 and the response will use the paginated format described below.
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&agent=john.doe@company.com&limit=500 will return the maximum (500) last leads for the agent email and the response will use the paginated format described below.
- https://www.encuentra24.com/api.php/v1/crm/index?slug=tu-auto-ideal&limit=500 will return the maximum (500) last leads and the response will use the paginated format described below.

**NOTE:** Don't forget these requests will not be valid without the x-api-key header!

### Responses

### Simple Response

Response will be an array of leads in JSON format, each of the leads with the following fields:

- id ID of the lead. You might want to use it in order to control which leads you have already imported in previous calls.
- adid Encuentra24 ID for the ad that received the lead.
- title Title of the ad that received the lead.
- sourceid The ID of the ad on your company's system (if applicable).
- created_at Timestamp of the lead.
- origin Origin of the lead. Possible values: \[ E24_MESSAGE | E24_CHAT | PHONECALL \]
- status Status of the lead. Possible values: \[ CONTACTED | SENTINFO | APPOINTMENT | SENDMOREOFFERS | SEEKMOREPROPERTIES | NEGOCIATING | LOST | WON \]
- agent Email of the agent assigned
- preview Preview of the content of the lead
- message Content of the message, only if origin is E24_MESSAGE
- curriculum Link to file, only if origin is E24_MESSAGE, ad is a job post and it was attached by the contact
- chat Link to the chat in Encuentra24, only if origin es E24_CHAT
- contact Person who created the lead. Is an **object** with the following fields:
    - id ID of the contact
    - name Name and lastname of the contact
    - email Email address
    - phone Phone number
- additionaldata Additional data of the lead. Is an **object** with the following fields:
    - rut RUT of the contact
    - incomeMin Minimum income of the contact
    - incomeMax Maximum income of the contact
    - code Code of variation
    - rooms Number of rooms
    - bathrooms Number of bathrooms
    - minTotalSquareMeters Minimum total square meters
    - maxTotalSquareMeters Maximum total square meters
    - totalTypologies Total typologies
    - minPrice Minimum price
    - maxPrice Maximum price
    - idProject ID of the project
    - date Date of the lead
    - time Time of the lead

    - adid Encuentra24 ID for the ad that received the lead.

    - sourceid The ID of the ad on your company's system (if applicable).
    - created_at Timestamp of the lead.
    - origin Origin of the lead. Possible values: \[ E24_MESSAGE | E24_CHAT | PHONECALL \]
    - status Status of the lead. Possible values: \[ CONTACTED | SENTINFO | APPOINTMENT | SENDMOREOFFERS | SEEKMOREPROPERTIES | NEGOCIATING | LOST | WON \]

    - curriculum Link to file, only if origin is E24_MESSAGE, ad is a job post and it was attached by the contact
    - chat Link to the chat in Encuentra24, only if origin es E24_CHAT
    - contact Person who created the lead. Is an **object** with the following fields:
        - id ID of the contact
        - name Name and lastname of the contact
        - email Email address
        - phone Phone number
    - additionaldata Additional data of the lead. Is an **object** with the following fields:
        - rut RUT of the contact
        - incomeMin Minimum income of the contact
        - incomeMax Maximum income of the contact
        - code Code of variation
        - rooms Number of rooms
        - bathrooms Number of bathrooms
        - minTotalSquareMeters Minimum total square meters
        - maxTotalSquareMeters Maximum total square meters
        - totalTypologies Total typologies
        - minPrice Minimum price
        - maxPrice Maximum price

        - date Date of the lead
        - time Time of the lead
- pagination Object with the following fields:
    - nextid ID of the next lead to be fetched
    - limit Number of records fetched

## Stats API

Now you can use our Stats API to get information about the leads generated by your ads in Encuentra24

This is the endpoint URL:

https://www.encuentra24.com/api.php/v1/ad/stats

### API key

In your requests, you have to add your API key in a header named x-api-key. **Your API key is:**

**66745cd97e505**

### Company slug parameter

**Required**, you have to add a GET parameter with the name of your company. The name of the parameter is slug and the value, for your company, is tu-auto-ideal.

### Range of dates parameters

**Required**, you have to add a GET parameters with the names of the range of dates. The name of the parameters are from and to and the value format is YYYY-MM-DD.

**Optional**, you can pass additional GET parameter to access a paginated response and indicate the position of the records to start. The name of the parameter is offset.

### Examples of requests

- https://www.encuentra24.com/api.php/v1/ad/stats?slug=tu-auto-ideal&from=2024-01-01&to=2024-01-31 will return the stats for your ads in Encuentra24 from January 1st to January 31st, 2024

**NOTE:** Don't forget these requests will not be valid without the x-api-key header!

### Simple Response

Response will be an array of stats by ads in JSON format, each one with the following fields:

- id ID of the ad
- title Title of the ad
- category Category of the ad
- region Region of the ad
- price Price of the ad
- added Date when the ad was added
- details Details of the ad
- impressions Number of impressions
- views Number of views
- calls_or_show_phone Number of calls or show phone
- whatsapp_or_sms Number of WhatsApp or SMS
- emails Number of emails
- pdf Number of PDF visits
- chats Number of chats
- favorites Number of favorites
- email Email of the agent assigned

### Paginated Response

Response will be an array of stats by ads in JSON format, stat information is inside the data node and meta node contains information about pagination:

- data
    - id ID of the ad
    - title Title of the ad
    - category Category of the ad
    - region Region of the ad
    - price Price of the ad
    - added Date when the ad was added
    - details Details of the ad
    - impressions Number of impressions
    - views Number of views
    - calls_or_show_phone Number of calls or show phone
    - whatsapp_or_sms Number of WhatsApp or SMS
    - emails Number of emails
    - pdf Number of PDF visits
    - chats Number of chats
    - favorites Number of favorites
    - email Email of the agent assigned
- meta
    - totalRecords Total number of records found
    - offset Starting record position
    - totalCurrentPage Total number of records in the current page by offset

## Featured Ads

Now you can use our Featured Ads API to feature your ads in Encuentra24.

This is the endpoint URL:

https://www.encuentra24.com/api.php/v1/ad/featured

- 

**POST**

### API key

In your requests, you have to add your API key in a header named x-api-key. **Your API key is:**

**66745cd97e505**

### Parameters as JSON

- slug Name of the company slug. **Required**.
- adId ID of the ad you want to feature. **Required**.
- productCode These codes are allowed: silver, gold, platinum. **Required**.

### Examples of body

- { "slug": "tu-auto-ideal", "adId": 12345678, "productCode": "gold" }

**NOTE:** Don't forget these requests will not be valid without the x-api-key header!

### Response as JSON

- status Possible values are ok or error.
- errors Array with errors returned only if status is error
- message Message returned when status is ok.
- ref Reference to the ad that was featured, returned only if status is ok.

### Example of response

Success response - **200**

{      "status": "ok",      "ref": "47586547",      "message": "Ad will be featured with silver product"    }

Error response - **400**

{      "status": "error",      "errors": {        "payment": "Invalid adId or productCode"      }    }

Error response - **404**

{      "status": "error",      "errors": {          "payment": "Ad not found or already featured or expired"      }    }

[Back to top](https://www.encuentra24.com/account/cnImport/xmlmanual#top)

Only **XML** and **Excel** (xlsx) formats are accepted.

XML file(s) must be UTF-8 encoded.

### General structure

[Back to top](https://www.encuentra24.com/account/cnImport/xmlmanual#top)

There are three kind of fields: **settings fields**, **ad fields** and **contact fields**.

Ad fields may vary depending on the **type** of ad. We'll talk about types of ads later.

There are required fields and optional fields. Optional fields can be included with empty values or simply discarded.

It is recommended that you [download a sample XML or XLS file](https://www.encuentra24.com/account/cnImport/importdemo). Will be a good starting point for generating you feed and getting to know the structure with a real ad.

### Desciption of the fields

[Back to top](https://www.encuentra24.com/account/cnImport/xmlmanual#top)

### Settings fields

- language - Main language of the feed and field values. Values es and en are accepted.
- type - Type of the ad (more info and list of types in [next section](https://www.encuentra24.com/account/cnImport/xmlmanual#types-of-ads))

### Ad fields

- sourceid - The unique identifier of your ad in your database. This identifier is unique in your database, but doesn't have to be unique in the import file. You can include it more than once, with different categories, if you need to make two ads for it. A common case is the same house being for sale or for rent.
- countryid - The ID of the country in which the ad will be displayed:
    - Panamá: **934**
    - Costa Rica: **2**
    - El Salvador: **919**
    - Guatemala: **2488**
    - Nicaragua: **152**
    - Honduras: **905**
    - Dominicana: **875**
    - Colombia: **521**
    - Puerto Rico: **427**
    - Chile: **5247**
- categoryid - The ID of the specific category in which the ad will be displayed. In [next section](https://www.encuentra24.com/account/cnImport/xmlmanual#types-of-ads) you can see the list of categories and their IDs.
- regionid - The ID of the region Here you can see the region list per country: \[ [Panamá](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Costa Rica](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [El Salvador](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Guatemala](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Nicaragua](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Honduras](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Dominicana](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Colombia](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Puerto Rico](https://www.encuentra24.com/account/cnImport/xmlmanual) \] \[ [Chile](https://www.encuentra24.com/account/cnImport/xmlmanual) \]
- type - In XML format, ads of different types can be provided in same file. So if you specify type as an ad field, it will override the setting field.
- title - The title of the ad (primary language is Spanish).
- title1 \[optional\] - Title of the ad in the second language (secondary language is English).
- descr \[optional\] - Text describing the ad (primary language is Spanish).
- descr1 \[optional\] - Text describing the ad in the second language (secondary language is English).
- picture \[optional, multi\] - URL of a picture for the ad. For XML file, you can include as many picture fields as photos you have. In the case of XLS file, you can add as many URLs as you desire in the same cell, separated by line breaks.
- location-lat \[optional\] - Latitude of the coordinates of the exact location
- location-long \[optional\] - Longitude of the coordinates of the exact location
- location-zoom \[optional\] - Zoom to show the exact location in Google Maps (if not present, defaults to 14)
- repost \[optional\] - Specifies time in which ad repost will be performed, in formatted as HH:mm (24 hour format). Remember that repost has a cost for the user, and user must have encuentra24 credits in their account in order for repost to be performed. If user has no credits at the specified repost time, repost will be ignored
- sold \[optional\] - Specifies whether or not the ad will be marked as sold. Possible values: 0 (no) or 1 (yes). If not field is not passed, default value is not sold.
- The rest of ad fields depend on the type provided. In [next section](https://www.encuentra24.com/account/cnImport/xmlmanual#types-of-ads) you can see the **list of types** and the fields for them.

### Contact fields

- email - Email to receive user contacts.
- phone - Phone number to be published.
- contact - Name of the advertiser.
- city - City where advertiser is located.
- company \[optional\] - Name of the company.
- phone2 \[optional\] - Another phone number to be published.
- addr \[optional\] - Address of advertiser.
- url \[optional\] - Url of the advertiser.
- skype \[optional\] - Skype user of the advertiser.
- licence \[optional\] - Company or realtor licence number (for real estate ads).

### Encuentra24 Entrega a Domicilio

[Back to top](https://www.encuentra24.com/account/cnImport/xmlmanual#top)

Most ads (with some exceptions) in types general, autoaccessories and Wholesale are eligible to be sold in our Encuentra24 Safe Shopping platform.

In order to enable it, it's necessary to add the safeshopping section, containing the fields below:

- size \[optional\] - Size of the package to be delivered. Allowed values here are:
    - s. Caja pequeña. Max. 15kg
    - m. Caja mediana. Max. 30kg
    - l. Caja grande. Max. 60kg

If not provided we will calculate one size based on the product category. Nonetheless, we strongly recommend that you provide us with the correct size.

- address \[optional\] - Address where the rider will pick up the product. You don't have any address configured yet. [You can do it here](https://www.encuentra24.com/account/cnC2cAccount/info). If not provided, it will default to first address configured. If no addresses configured, safe shopping will still be activated but an address must be provided before processing your first sell order.
- stock \[optional\] - Stock of the product. \[will default to 1 if not provided, or to sum of stock of variations of the product if those are provided\]
- shippingcover \[optional\] - In case you will pay for the shipping, you can set here the max amount to cover -buyer will pay the rest. Set 0 or don't send the field if buyer will pay for shipping.
- applytax \[optional\] - Possible values: 0 and 1. Send 1 if you need us to add taxes to the product in the checkout page or 0 otherwise. If this field is not sent, it will default to the general value you set in your [config page](https://www.encuentra24.com/account/cnC2cAccount/info)

Before selling on Encuentra24 Safe Shopping you must verify your indentity. [Do it here](https://www.encuentra24.com/account/cnIdentity/wizard)

In **XLS import**, these fields will be prefixed with safeshopping_. Examples: safeshopping_size, safeshopping_stock, etc.

Additionally, a field safeshopping_enabled with value 1 is required in XLS in order to enable the ad.

### Ad variations

[Back to top](https://www.encuentra24.com/account/cnImport/xmlmanual#top)

If your account supports ad variations and so does the type of the ad, you can add variations for your ads. Variations are only supported for XML import!

First of all, you need to choose the desired **variation theme** for the ad. Here you can see all supported variation themes (per type of ad) at the moment:

| **Type name** | **Variation theme name** | **Variable fields** |
| --- | --- | --- |
| general | color | color |
| general | size | size |
| general | color-size | color, size |
| general | format | format |
| general | flavor | flavor |
| general | flavor-format | flavor, format |
| projects | units | modelnr1, unitname, square, usefulm2, terracem2, rooms, bath, orientation, floor |

All variable fields are required. And, apart from the variable fields, all variations will also include the fields below:

- vendorid - Unique identifier for the variation in your company's system.
- price - Price for the variation.
- stock - Stock for the variation on Encuentra24 Safe Shopping.
- picture \[optional\] - URL for the photo of the variation.
- picture \[optional\] - Another picture (as many as needed).

If variations are provided, pictures for the ad are ignored and only pictures of variations will be valid.
